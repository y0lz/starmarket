## 🔄 Потоки навигации

### 1️⃣ Покупка товара

```
Главная
  ↓
Выбор игры (клик на карточку)
  ↓
Детальный вид игры
  ↓
[Опционально] Выбор категории
  ↓
[Опционально] Применение сортировки
  ↓
Клик на товар
  ↓
Модальное окно товара
  ↓
Кнопка "Купить"
  ↓
Оплата через Telegram Stars
```

### 2️⃣ Фильтрация товаров

```
Детальный вид игры
  ↓
Выбор категории (например, "Валюта")
  ↓
Товары отфильтрованы
  ↓
[Опционально] Применение сортировки
  ↓
[Опционально] Использование поиска
```

### 3️⃣ Возврат назад

```
Детальный вид игры
  ↓
Клик "← Назад к играм"
  ↓
Главная страница (каталог игр)
```

### 4️⃣ Переход в профиль

```
Любая страница
  ↓
Клик на кнопку "Профиль" (в шапке)
  ↓
Кабинет продавца
```

## 🎯 Состояния приложения

### Главная страница
```javascript
{
  view: 'games',           // Показываем каталог игр
  currentGame: null,       // Игра не выбрана
  carousel: 'running'      // Карусель работает
}
```

### Детальный вид игры
```javascript
{
  view: 'gameDetail',      // Показываем детали игры
  currentGame: {           // Выбранная игра
    id: 'wow',
    name: 'World of Warcraft'
  },
  selectedCategory: null,  // Категория не выбрана (все)
  sortBy: 'default',       // Сортировка по умолчанию
  searchQuery: ''          // Поиск пустой
}
```

### С фильтрами
```javascript
{
  view: 'gameDetail',
  currentGame: { id: 'wow', name: 'World of Warcraft' },
  selectedCategory: 'Валюта',  // Выбрана категория
  sortBy: 'price-asc',         // Сортировка по цене
  searchQuery: 'золото'        // Поиск по слову
}
```

## 📱 Жесты и взаимодействия

### Карусель
- **Свайп влево/вправо** - переключение слайдов
- **Тап на точку** - переход к слайду
- **Касание** - пауза автопрокрутки

### Карточки
- **Тап** - открытие детального вида
- **Долгое нажатие** - нет действия

### Модальное окно
- **Тап на ×** - закрытие
- **Тап вне окна** - закрытие
- **Свайп вниз** - закрытие (будущая функция)

---

## 🔍 Поиск

### Где работает поиск:

✅ **Работает:**
- В детальном виде игры (поиск внутри игры)

❌ **Не работает:**
- На главной странице (каталог игр)
- Поиск по всем играм сразу

### Как работает:

```
Пользователь вводит: "золото"
  ↓
Фильтруются товары текущей игры
  ↓
Показываются только товары с "золото" в названии/описании
```

---

## 🎯 Быстрые действия

### Горячие клавиши (будущая функция)
- `Esc` - закрыть модальное окно
- `←` - предыдущий слайд карусели
- `→` - следующий слайд карусели
- `/` - фокус на поиск

### Кнопки навигации
- **← Назад к играм** - возврат к каталогу
- **Профиль** - переход в кабинет
- **× (в модальном окне)** - закрытие

## 📱 Адаптивность

### Мобильные (< 768px)
- Каталог игр: 3 колонки
- Товары: 2 колонки
- Карусель: полная ширина

### Планшеты (768px - 1024px)
- Каталог игр: 3 колонки
- Товары: 3 колонки
- Карусель: полная ширина

### Десктоп (> 1024px)
- Каталог игр: 4-5 колонок
- Товары: 3-4 колонки
- Карусель: ограничена max-width
