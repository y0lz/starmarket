## 🎨 Главная страница (index.html)

### Новая структура:

1. **Карусель баннеров** 
   - Автоматическая прокрутка каждые 4 секунды
   - 3 баннера с информацией о платформе
   - Индикаторы (точки) для навигации

2. **Каталог игр**
   - Сетка 3x3 с карточками игр
   - Иконки и количество товаров для каждой игры
   - 9 популярных игр: WoW, Genshin, Fortnite, Roblox, CS2, ML, Valorant, LoL, Dota 2

3. **Детальный вид игры** (после выбора)
   - Кнопка "Назад к играм"
   - Информация об игре
   - Категории товаров: Валюта, Предметы, Аккаунты, Персонажи, Косметика, Услуги
   - Сортировка: По умолчанию, Цена ↑, Цена ↓, По названию
   - Сетка товаров

## 🎮 Навигация

### Главная страница:
```
Главная → Выбор игры → Категории → Товары → Детали товара
```

### Возврат:
```
Детали игры → [Назад к играм] → Главная
```

## 🔧 Основные функции JavaScript

### Карусель:
- `initCarousel()` - Инициализация карусели
- `goToSlide(index)` - Переход к слайду
- `nextSlide()` - Следующий слайд
- `startCarousel()` / `stopCarousel()` - Управление автопрокруткой

### Каталог игр:
- `renderGames()` - Отрисовка каталога игр
- `selectGame(gameId)` - Выбор игры
- `backToGames()` - Возврат к каталогу
- `renderGameCategories(gameId)` - Отрисовка категорий игры
- `selectCategory(category)` - Выбор категории

### Товары:
- `filterProducts()` - Фильтрация товаров
- `renderProducts(products)` - Отрисовка товаров
- `showProductModal(productId)` - Показ модального окна товара

## 🎨 CSS классы

### Карусель:
- `.carousel-container` - Контейнер карусели
- `.carousel-wrapper` - Обертка слайдов
- `.carousel-slide` - Отдельный слайд
- `.carousel-dots` - Индикаторы
- `.carousel-dot.active` - Активный индикатор

### Каталог игр:
- `.games-grid` - Сетка игр
- `.game-card` - Карточка игры
- `.game-card-icon` - Иконка игры
- `.game-card-name` - Название игры
- `.game-card-count` - Количество товаров

### Детальный вид:
- `.game-detail-header` - Шапка детального вида
- `.game-detail-back` - Кнопка возврата
- `.game-detail-info` - Информация об игре

## 📱 Адаптивность

- Карусель: 100% ширины, высота 180px
- Каталог игр: сетка 3 колонки
- Товары: сетка 2 колонки
- Все элементы адаптированы под мобильные устройства

## 🎯 Особенности

1. **Автоматическая карусель** с паузой при взаимодействии
2. **Динамический подсчет** товаров для каждой игры
3. **Фильтрация по категориям** внутри игры
4. **Поиск** работает только внутри выбранной игры
5. **Сортировка** применяется к отфильтрованным товарам
6. **Плавные переходы** между видами

## 🚀 Запуск

1. Откройте `index.html` в браузере или через Telegram Web App
2. Выберите игру из каталога
3. Выберите категорию товаров
4. Примените сортировку при необходимости
5. Нажмите на товар для просмотра деталей
