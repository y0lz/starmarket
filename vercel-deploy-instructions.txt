=== ИНСТРУКЦИЯ ПО ДЕПЛОЮ НА VERCEL ===

Проект обновлен, но нужно задеплоить на Vercel вручную.

ВАРИАНТ 1: Через Vercel Dashboard (самый простой)
1. Откройте https://vercel.com/dashboard
2. Найдите проект "mini-app"
3. Перейдите в Settings → Git
4. Подключите GitHub репозиторий (или создайте новый)
5. Vercel автоматически задеплоит при push

ВАРИАНТ 2: Через Vercel CLI (требует авторизации)
1. Откройте https://vercel.com/account/tokens
2. Создайте новый токен
3. Экспортируйте: export VERCEL_TOKEN=ваш_токен
4. Запустите: vercel --prod --token=$VERCEL_TOKEN

ВАРИАНТ 3: Загрузить файлы вручную
1. Откройте https://vercel.com/new
2. Выберите "Import Project"
3. Загрузите файлы из /root/mini-app/
4. Укажите project name: mini-app
