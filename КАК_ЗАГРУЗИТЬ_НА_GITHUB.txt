СПОСОБ 1: Через CMD (РЕКОМЕНДУЕТСЯ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Нажмите Win+R
2. Введите: cmd
3. Нажмите Enter
4. Скопируйте и вставьте эти команды:

cd /d "c:\Users\mainz\OneDrive\Рабочий стол\starptod\starmarket"
git add .
git commit -m "Security fixes and documentation update - v2.0.0"
git push origin main

Если ошибка "main doesn't exist", попробуйте:
git push origin master

СПОСОБ 3: Через VS Code (САМЫЙ ПРОСТОЙ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Откройте VS Code
2. File → Open Folder → выберите папку starmarket
3. Нажмите Ctrl+Shift+G (Source Control)
4. Нажмите "+" рядом с "Changes" (добавить все файлы)
5. Введите сообщение: "Security fixes and documentation update - v2.0.0"
6. Нажмите ✓ (Commit)
7. Нажмите "..." → Push

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Если видите ошибку "not a git repository", выполните:

cd /d "c:\Users\mainz\OneDrive\Рабочий стол\starptod\starmarket"
git init
git remote add origin https://github.com/ВАШ_USERNAME/starmarket.git
git branch -M main
git add .
git commit -m "Initial commit - v2.0.0"
git push -u origin main

Замените ВАШ_USERNAME на ваш GitHub username!

⚠️  ЕСЛИ ОШИБКА АУТЕНТИФИКАЦИИ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Если видите "Permission denied" или "Authentication failed":

1. Используйте Personal Access Token:
   • GitHub → Settings → Developer settings → Personal access tokens
   • Generate new token (classic)
   • Выберите scopes: repo
   • Скопируйте токен

2. При push используйте токен вместо пароля:
   Username: ваш_username
   Password: ваш_токен

Или настройте SSH:
   https://docs.github.com/en/authentication/connecting-to-github-with-ssh

После успешной загрузки на GitHub:

1. ⚠️  КРИТИЧНО: Замените скомпрометированные ключи
   См. файл: SETUP_AFTER_SECURITY_FIX.md

2. Создайте .env файл локально
   cp .env.example .env
   Заполните НОВЫМИ ключами

3. Настройте переменные в Vercel
   Settings → Environment Variables

4. Передеплойте проект
   git push (Vercel автоматически задеплоит)

5. Протестируйте
   • Бот отвечает на /start
   • Mini App открывается
   • Игры загружаются
