# Changelog - StarMarket

## [2.0.0] - Обновление структуры

### ✨ Добавлено

#### Главная страница:
- 🎠 **Карусель баннеров** на главной странице
  - 3 информационных баннера
  - Автоматическая прокрутка каждые 4 секунды
  - Индикаторы навигации (точки)
  - Пауза при взаимодействии пользователя

- 🎮 **Каталог игр**
  - Сетка 3x3 с карточками игр
  - 9 популярных игр с иконками
  - Счетчик товаров для каждой игры
  - Плавная анимация при нажатии

- 📂 **Детальный вид игры**
  - Кнопка возврата к каталогу
  - Информация о выбранной игре
  - Категории товаров (Валюта, Предметы, Аккаунты и др.)
  - Сортировка товаров
  - Сетка товаров для выбранной игры

#### Структура проекта:
- 📁 Разделение HTML и CSS
  - `css/main.css` - стили главной страницы
  - `css/add-product.css` - стили добавления товара
  - `css/my-products.css` - стили управления товарами
  - `css/profile.css` - стили профиля

### 🔄 Изменено

- Переработана навигация: Главная → Игра → Категория → Товар
- Улучшена структура кода (разделение HTML/CSS)
- Оптимизирована фильтрация товаров
- Обновлен дизайн карточек игр

### 🎨 Улучшения UI/UX

- Более интуитивная навигация
- Визуальная иерархия контента
- Плавные переходы между экранами
- Адаптивный дизайн для мобильных устройств

### 🐛 Исправлено

- Улучшена производительность при большом количестве товаров
- Исправлена фильтрация по категориям
- Оптимизирована работа поиска
