# 🚀 Быстрая настройка после исправлений безопасности

## ⚠️ ВАЖНО: Ваши старые ключи скомпрометированы!

Следуйте этим шагам **по порядку**:

## Шаг 1: Получите новый токен бота

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/mybots`
3. Выберите вашего бота
4. Нажмите **API Token**
5. Нажмите **Revoke current token** (отозвать текущий)
6. Скопируйте **новый токен** (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Получите новые ключи Supabase

1. Откройте [Supabase Dashboard](https://app.supabase.com)
2. Выберите ваш проект
3. Перейдите в **Settings** → **API**
4. Нажмите **Reset** рядом с **anon public** ключом
5. Скопируйте:
   - **Project URL** (например: `https://xxxxx.supabase.co`)
   - **anon public** ключ (длинная строка начинающаяся с `eyJ...`)

## Шаг 3: Создайте .env файл

В корне проекта создайте файл `.env` (без расширения):

```env
TELEGRAM_BOT_TOKEN=ваш_новый_токен_из_шага_1
SUPABASE_URL=ваш_url_из_шага_2
SUPABASE_ANON_KEY=ваш_ключ_из_шага_2
MINI_APP_URL=https://ваш-домен.vercel.app
```

**Пример:**
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
SUPABASE_URL=https://gjainivmaudjxmhgrcnp.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
MINI_APP_URL=https://mini-app-pi-ivory.vercel.app
```

## Шаг 4: Настройте переменные в Vercel

1. Откройте [Vercel Dashboard](https://vercel.com/dashboard)
2. Выберите ваш проект
3. Перейдите в **Settings** → **Environment Variables**
4. Добавьте каждую переменную:

| Name | Value | Environment |
|------|-------|-------------|
| `TELEGRAM_BOT_TOKEN` | ваш новый токен | Production, Preview, Development |
| `SUPABASE_URL` | ваш Supabase URL | Production, Preview, Development |
| `SUPABASE_ANON_KEY` | ваш новый ключ | Production, Preview, Development |
| `MINI_APP_URL` | ваш домен Vercel | Production, Preview, Development |

5. Нажмите **Save** для каждой переменной

## Шаг 5: Передеплойте проект

```bash
# Закоммитьте изменения
git add .
git commit -m "Security fixes: remove hardcoded secrets"
git push

# Vercel автоматически передеплоит проект
```

Или вручную в Vercel Dashboard:
1. Перейдите в **Deployments**
2. Нажмите **Redeploy** на последнем деплое

## Шаг 6: Запустите бота локально (для тестирования)

```bash
# Установите зависимости (если еще не установлены)
npm install

# Запустите бота
npm start
```

Если видите:
```
🤖 StarMarket бот запущен!
📱 Mini App URL: https://...
```

Значит все работает! ✅

Если видите ошибку:
```
❌ TELEGRAM_BOT_TOKEN is not set in environment variables!
```

Значит .env файл не найден или неправильно заполнен.

## Шаг 7: Проверьте работу

### Проверка бота:
1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте `/start`
4. Должно появиться приветственное сообщение с кнопками

### Проверка Mini App:
1. Нажмите кнопку "🛍️ Открыть магазин"
2. Должна открыться главная страница с играми
3. Попробуйте открыть игру и посмотреть товары

### Проверка добавления товара:
1. Откройте форму добавления товара
2. Заполните все поля
3. Нажмите "Добавить товар"
4. Должно появиться сообщение об успехе

## ❌ Если что-то не работает

### Ошибка: "Missing environment variables"
**Причина:** Переменные не установлены в Vercel  
**Решение:** Повторите Шаг 4

### Ошибка: "Database temporarily unavailable"
**Причина:** Неправильный SUPABASE_URL или SUPABASE_ANON_KEY  
**Решение:** Проверьте значения в Vercel, повторите Шаг 2

### Ошибка: Бот не отвечает
**Причина:** Неправильный TELEGRAM_BOT_TOKEN  
**Решение:** Проверьте токен, повторите Шаг 1

### Ошибка: "Invalid game_id or category_id"
**Причина:** База данных не содержит игры и категории  
**Решение:** Выполните миграцию `migration-games-categories.sql`
