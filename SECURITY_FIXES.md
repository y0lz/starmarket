## 🚨 КРИТИЧЕСКИ ВАЖНО!

### Ваши старые ключи скомпрометированы!

Поскольку токены и ключи были в публичном репозитории, их нужно **немедленно заменить**:

#### 1. Telegram Bot Token
```bash
# Зайдите в @BotFather
/mybots → Выберите бота → API Token → Revoke current token
# Получите новый токен
```

#### 2. Supabase Keys
```bash
# Зайдите в Supabase Dashboard
# Settings → API → Reset anon key
# Получите новые ключи
```

#### 3. Создайте .env файл
```bash
# В корне проекта создайте файл .env
cp .env.example .env

# Заполните НОВЫМИ значениями:
TELEGRAM_BOT_TOKEN=ваш_новый_токен
SUPABASE_URL=ваш_supabase_url
SUPABASE_ANON_KEY=ваш_новый_ключ
MINI_APP_URL=https://ваш-домен.vercel.app
```

#### 4. Настройте переменные в Vercel
```bash
# Зайдите в Vercel Dashboard
# Ваш проект → Settings → Environment Variables
# Добавьте все переменные из .env
```

## 🔐 Правила безопасности

### ✅ ВСЕГДА:
- Используйте переменные окружения для секретов
- Валидируйте все входящие данные
- Обрабатывайте ошибки правильно
- Логируйте подозрительную активность
- Используйте HTTPS
- Проверяйте права доступа

### ❌ НИКОГДА:
- Не коммитьте .env файлы
- Не храните секреты в коде
- Не доверяйте данным от клиента
- Не игнорируйте ошибки
- Не используйте `SELECT *` без необходимости
- Не отключайте CORS полностью
